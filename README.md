# BÁO TƯỜNG ĐIỆN TỬ 20/11 – CHUYẾN ĐÒ TRI THỨC

Ấn phẩm điện tử chào mừng Ngày Nhà giáo Việt Nam 20/11/2026.

## Xem mã nguồn
Mở file `index.html` trong repository.

## Bật website miễn phí bằng GitHub Pages
1. Mở repository **BAO-TUONG-DIEN-TU-20-11**.
2. Chọn **Settings → Pages**.
3. Ở mục **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn branch **main**, thư mục **/(root)**, nhấn **Save**.
5. Chờ GitHub triển khai. Địa chỉ website dự kiến:
   https://tranphuc2026abc-prog.github.io/BAO-TUONG-DIEN-TU-20-11/

## Logo
